Privacy Policy

Turnaround Tracker Backup is a private, personal-use OAuth client operated by the repository owner.

The application uses Google Drive only to create, read, update, and delete backup files that the application itself manages. Access is limited to the Google Drive file scope (drive.file).

Backup files are encrypted before upload. OAuth credentials and tokens are stored locally on the owner's Raspberry Pi and are not published in this repository.

No Google user data is sold, shared with third parties, or used for advertising, analytics, profiling, or any public service.

The application is intended for the owner's own backup workflow only.
